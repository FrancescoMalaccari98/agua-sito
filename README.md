# Aqua – Sito

## Branch
- **main** – versione finale / per accettazione del cliente
- **devops** – branch di sviluppo

Si sviluppa su `devops`; quando una versione è pronta per il cliente si fa merge di `devops` in `main`.

## Indirizzi
- Sito pubblico (branch `main`): https://francescomalaccari98.github.io/aqua-sito/
- Carta per il QR code: https://francescomalaccari98.github.io/aqua-sito/carta.html
- Il menu si modifica in `data/menu.properties`
- Le foto del sito si scelgono in `data/foto.properties` (ogni voce ha un commento con la sua posizione nella pagina)
